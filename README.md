# Adhan audio

Audio for the Prayer Times and Adhkar Alexa skill.

- `adhan-nourin-siddiq.mp3` — Adhan (Islamic call to prayer) by
  Sheikh Nourin Muhammad Siddiq (Sudanese reciter, 1982–2020),
  sourced from the recording "Powerful Adhan by Sheikh Noreen
  Mohammed Siddiq" (YouTube, Islamic Hub Community, 2026-01-02).
  Standard adhan (no Fajr phrase). 178 s, MP3 128 kbps.
- `adhan-fajr-abdellatif-alawad.mp3` — Fajr adhan by Sheikh Abdul
  Latif Al-Awad (Sudanese), sourced from the recording "اذان الفجر
  رائع جدا من جمهورية السودان / الشيخ عبد اللطيف العوض" (YouTube,
  القرآن المجيد Quran Majeed Ch). Includes "as-salatu khayrun min
  an-nawm" (verified by local transcription, twice). First 4 s
  (channel intro) trimmed. 123 s, MP3 128 kbps.
- Served over HTTPS via GitHub Pages for Alexa AudioPlayer:
  `https://mahmedsud16-stack.github.io/adhan-audio/adhan-nourin-siddiq.mp3`
  `https://mahmedsud16-stack.github.io/adhan-audio/adhan-fajr-abdellatif-alawad.mp3`
